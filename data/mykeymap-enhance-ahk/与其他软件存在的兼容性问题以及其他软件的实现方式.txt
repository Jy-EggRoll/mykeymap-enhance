### 二、光标样式切换的 AHK 核心逻辑
#### 1. 基础准备：注册表/API 常量定义
AHK 脚本首先定义 Windows 光标管理的核心常量和 API 调用声明，为后续操作铺垫：
```autohotkey
; 定义 Windows API 常量（光标设置专用）
SPI_SETCURSORS := 0x0057       ; 刷新光标设置
SPI_SETMOUSESCHEME := 0x007E   ; 设置光标方案
SPIF_UPDATEINIFILE := 0x01     ; 更新系统配置文件
SPIF_SENDCHANGE := 0x02        ; 通知系统配置变更

; 声明调用 Windows API（SystemParametersInfo 是核心）
DllCall("SystemParametersInfo", "UInt", SPI_SETMOUSESCHEME, "UInt", 0, "Str", "", "UInt", SPIF_UPDATEINIFILE | SPIF_SENDCHANGE)
```

#### 2. 核心功能1：加载自定义光标样式
逻辑流程：  
- 读取用户配置的「标准化光标文件目录」（经 `handle-cursor-style.ps1` 处理后的目录）；  
- 生成光标方案的 `.inf` 配置文件（Windows 标准光标方案格式）；  
- 调用 API 应用该光标方案，并写入注册表持久化；  
- 刷新光标显示，确保即时生效。

核心 AHK 代码逻辑（还原）：
```autohotkey
; 加载自定义光标方案
LoadCustomCursorScheme(cursorDir) {
    ; 步骤1：验证光标目录是否存在标准光标文件（Arrow.cur、Hand.cur 等）
    if !FileExist(cursorDir "\Arrow.cur") {
        ToolTip, "光标目录缺少标准文件，请检查！"
        return
    }

    ; 步骤2：生成 Windows 标准的光标方案 .inf 文件
    infContent := "[Version]`nSignature=`"`$CHICAGO$`"`n[DefaultInstall]`nAddReg=AddCursorReg`n[AddCursorReg]`n"
    cursorTypes := ["Arrow", "Hand", "IBeam", "Wait", "SizeAll", "SizeNS", "SizeWE"] ; 标准光标类型
    for _, type in cursorTypes {
        filePath := cursorDir "\" type ".cur"
        if FileExist(filePath) {
            infContent .= "HKCU,Control Panel\Cursors," type ",0x00000000,""" filePath """`n"
        }
    }
    ; 写入 .inf 文件到临时目录
    infPath := A_Temp "\CustomCursorScheme.inf"
    FileDelete, %infPath%
    FileAppend, %infContent%, %infPath%, "UTF-8"

    ; 步骤3：调用 API 应用光标方案
    DllCall("SystemParametersInfo", "UInt", SPI_SETMOUSESCHEME, "UInt", 0, "Str", infPath, "UInt", SPIF_UPDATEINIFILE | SPIF_SENDCHANGE)
    
    ; 步骤4：刷新光标，强制生效
    DllCall("SystemParametersInfo", "UInt", SPI_SETCURSORS, "UInt", 0, "Ptr", 0, "UInt", 0)
    
    ; 步骤5：记录当前光标方案到配置文件，便于后续恢复
    IniWrite, %cursorDir%, %A_ScriptDir%\config.ini, Cursor, CurrentScheme
    ToolTip, "自定义光标方案已加载"
}
```

#### 3. 核心功能2：恢复系统默认光标样式
逻辑流程：  
- 读取注册表中「原始光标方案」（软件启动时提前备份）；  
- 调用 API 回写默认方案，恢复系统原生光标；  
- 刷新光标显示，清除自定义配置。

核心 AHK 代码逻辑（还原）：
```autohotkey
; 软件启动时备份默认光标方案（仅执行一次）
BackupDefaultCursorScheme() {
    ; 读取系统默认光标方案（注册表路径）
    RegRead, originalScheme, HKEY_CURRENT_USER, Control Panel\Cursors, Scheme Source
    ; 备份到配置文件
    IniWrite, %originalScheme%, %A_ScriptDir%\config.ini, Cursor, DefaultScheme
}

; 恢复默认光标方案
RestoreDefaultCursorScheme() {
    ; 读取备份的默认方案
    IniRead, originalScheme, %A_ScriptDir%\config.ini, Cursor, DefaultScheme
    if (originalScheme = "") {
        originalScheme := "Windows Default" ; 兜底默认值
    }

    ; 调用 API 恢复默认
    DllCall("SystemParametersInfo", "UInt", SPI_SETMOUSESCHEME, "UInt", 0, "Str", originalScheme, "UInt", SPIF_UPDATEINIFILE | SPIF_SENDCHANGE)
    ; 刷新光标
    DllCall("SystemParametersInfo", "UInt", SPI_SETCURSORS, "UInt", 0, "Ptr", 0, "UInt", 0)
    
    ; 清空当前光标方案配置
    IniDelete, %A_ScriptDir%\config.ini, Cursor, CurrentScheme
    ToolTip, "已恢复系统默认光标"
}
```

#### 4. 触发层：菜单/快捷键调用切换逻辑
光标切换功能通过「托盘菜单/快捷键」触发，AHK 中绑定逻辑如下：
```autohotkey
; 托盘菜单绑定（示例）
Menu, Tray, Add, 加载自定义光标, Menu_LoadCustomCursor
Menu, Tray, Add, 恢复默认光标, Menu_RestoreDefaultCursor
Menu, Tray, Add, 分隔符, -

; 菜单点击事件 - 加载自定义光标
Menu_LoadCustomCursor:
    ; 读取用户配置的光标目录（可通过配置界面设置）
    IniRead, cursorDir, %A_ScriptDir%\config.ini, Cursor, CustomDir
    if (cursorDir = "") {
        ; 弹出目录选择框
        FileSelectFolder, cursorDir, , , "选择标准化后的光标目录"
        if (cursorDir = "") return
        ; 保存到配置
        IniWrite, %cursorDir%, %A_ScriptDir%\config.ini, Cursor, CustomDir
    }
    LoadCustomCursorScheme(cursorDir)
return

; 菜单点击事件 - 恢复默认光标
Menu_RestoreDefaultCursor:
    RestoreDefaultCursorScheme()
return

; 快捷键绑定（示例，可自定义）
^!c:: ; Ctrl+Alt+C 切换光标
    IniRead, currentScheme, %A_ScriptDir%\config.ini, Cursor, CurrentScheme
    if (currentScheme = "") {
        ; 当前是默认，加载自定义
        Menu_LoadCustomCursor()
    } else {
        ; 当前是自定义，恢复默认
        Menu_RestoreDefaultCursor()
    }
return
```

#### 5. 辅助逻辑：光标状态监控与提示
软件的「实时提示」功能会监控光标方案状态，AHK 中通过定时读取注册表实现：
```autohotkey
; 定时检查光标状态（每秒1次）
CursorStateMonitor:
    RegRead, currentScheme, HKEY_CURRENT_USER, Control Panel\Cursors, Scheme Source
    if (currentScheme != A_PreviousScheme) {
        ; 更新状态提示（如悬浮窗/托盘提示）
        ToolTip, "当前光标方案：" (currentScheme = "Windows Default" ? "系统默认" : "自定义")
        A_PreviousScheme := currentScheme
    }
    SetTimer, CursorStateMonitor, 1000 ; 重复执行
return
```

### 三、关键补充说明
1. **标准化依赖**：  
   自定义光标目录必须经过 `handle-cursor-style.ps1` 处理，确保文件名为 Windows 标准名称（Arrow.cur、Hand.cur 等），否则 AHK 加载逻辑无法识别。
2. **权限与兼容性**：  
   无需管理员权限（光标设置写入 `HKEY_CURRENT_USER` 注册表项），兼容 Win10/11（代码库 ISSUE 模板明确适配）。
3. **配置持久化**：  
   所有光标相关配置（自定义目录、默认方案备份）均通过 `src/utils/ini.ahk` 读写 `config.ini`，确保软件重启后保留设置。

InputTip 中光标样式切换的 AHK 逻辑核心是：  
「备份默认→标准化文件→生成 INF 配置→调用 Windows API 应用/恢复→菜单/快捷键触发→状态监控提示」，全程基于 AHK 对 Windows 注册表和系统 API 的调用，实现光标样式的无缝切换与恢复。
